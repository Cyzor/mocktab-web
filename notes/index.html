Research Notes

What MockTab has learned about how drawing tablets talk to a computer, and how macOS expects a driver to talk to apps. Each claim is marked as seen on hardware, taken from the Linux driver, or unverified. The notes index on GitHub explains the labels.

Wacom pen protocols

  • Intuos Pro gen 3 — PTK-470/670/870 over USB and Bluetooth LE, including edge behavior
  • Intuos Pro gen 2 — PTH-x60, CTL-x100, and many pen displays over USB and Bluetooth
  • Intuos 10-byte format — Intuos 1–5, Intuos Pro gen 1, Intuos3, and the 2015–2018 consumer Intuos
  • Consumer tablets — Graphire, Bamboo, and the shared touch and key container
  • Pen displays — Cintiq, DTU, PL, Cintiq touch, and the ExpressKey Remote

Across Wacom tablets

  • Switching into full-data mode — the feature report every tablet needs, and where to send it
  • Pen tool codes — codes seen on hardware, and the eraser, Art Pen, and rotation rules
  • Wireless and battery — transports by model and battery encodings
  • LEDs and OLEDs — ring LEDs and Intuos4 key displays

Other

  • Xencelabs — Pen Tablet, Pen Display, and Quick Keys: input and host writes
  • macOS tablet event synthesis — the proximity, pen, click, and scroll fields apps check
  • Art Pen Rotation Observations — raw capture log
