A driver for unsupported Wacom tablets.

MockTab is a free, open-source driver for Wacom drawing tablets that no longer have official support on macOS.

One self-contained app bundle. MockTab processes pen input on a high-priority thread to keep input responsive.

MockTab supports a growing set of USB and Bluetooth Wacom tablets, plus some Xencelabs models. Check the Hardware page for your model’s status.

Purpose

Wacom tablets often outlast their official driver support. MockTab revives USB and Bluetooth Wacom tablets from the early 2000s through roughly 2020 on macOS 13 and later, plus some recent Xencelabs tablets. See Hardware for supported models and test status.

Tablet area

Maps part or all of the tablet to part or all of a display. Proportional mode keeps circles round, whatever the tablet’s shape.

Pen feel

Adjust input pressure, smoothing, double-click distance, and motion. Works with Photoshop, Affinity, Krita, Rebelle, Clip Studio, ZBrush, Blender, Nomad, and other pen-aware apps.

Button mapping

Assign key combinations, clicks, eraser toggle, or display cycling to barrel buttons, and express keys. Press a shortcut to record it.

Per-app overrides

Use separate settings for tablet area, pressure, button, and display for each application. MockTab applies them when the app becomes active.

Profiles

Save named snapshots of a tablet’s configuration. Drag JSON files in to import them; imports merge with existing settings instead of replacing them.

Display mapping

Map the tablet to one display or span all connected displays. Assign a button to cycle through them.

Touch

Use cursor movement, two-finger scrolling, pinch to zoom, and two-finger rotation on tablets with capacitive touch.

Scratchpad

Test pen input without opening an art app. See pressure, tilt, rotation, and button state as you draw.

Features

  • Pressure, tilt, and pen rotation
  • Per-app overrides for tablet area, pressure, buttons, and display routing
  • Multiple tablet generations connected at the same time
  • Wireless operation over Bluetooth and USB dongles
  • Touch ring and touch strip support
  • Capacitive touch, including two-finger scrolling, pinch to zoom, and two-finger rotation
  • Profile import and export as JSON with drag and drop
  • Undo and redo across every settings pane with ⌘Z
  • In-app help and a menu-bar mode that runs without a Dock icon
  • One self-contained app bundle

Unsupported

  • Huion, XP-Pen, and other non-Wacom vendors (Xencelabs is the exception — see Hardware)
  • Post-2020 Wacom devices (support requires further testing and verification)
  • Linux, Windows, iPad, and other operating systems (Mac only)

Frequently Asked Questions (FAQ)

Wacom says my tablet is no longer supported. What now?

Wacom's driver updates sometimes remove support for earlier generations of tablets. Reverting to a previous driver usually restores operation, as long as it still runs on your version of macOS. See Troubleshooting for common symptoms, affected device families, and other driver options.

What is MockTab?

MockTab is a driver for Wacom drawing tablets that no longer have official support on macOS.

How is MockTab different from Wacom’s driver or OpenTabletDriver?

Wacom’s driver is proprietary and no longer supports many older tablets. OpenTabletDriver is an open-source, cross-platform project with broad hardware support and extensive configuration options.

MockTab takes a narrower approach: it focuses on macOS and Wacom hardware. It does not install system extensions, daemons, or login items. That smaller scope keeps the app focused and simple.

My tablet works with Wacom’s driver or OpenTabletDriver. Why would I need this?

If your current driver works well for you, there’s no reason to change. MockTab is for tablets that official drivers no longer support, and for people who want a focused app designed specifically for macOS.

OpenTabletDriver is an excellent cross-platform project with broad hardware support and deep configuration options. MockTab is a focused, native Mac experience that feels at home and gets out of the way.

What tablets does MockTab support?

MockTab supports Wacom USB and Bluetooth tablets from the early 2000s through roughly 2020, including Intuos, Intuos Pro, Cintiq, Bamboo, and Graphire families.

Many models have confirmation from real hardware. Others rely on Linux kernel and OpenTabletDriver device references and still need testing. Hardware lists every registered model and its current status.

Can I use an iPad as a drawing tablet?

Yes, but not with MockTab. Astropad Slate and Apple’s built-in Sidecar can make an iPad operate like a dedicated tablet.

What are the system requirements?

macOS 13 (Ventura) or later, on Apple Silicon or Intel. A supported Wacom tablet over USB or Bluetooth. About 10 MB on disk.

Is there a version for Linux, Windows, or other platforms?

No. Mac only. For Linux and Windows, try OpenTabletDriver.

How do I install it?

Download the latest disk image (.dmg) from Releases, drag MockTab.app into your Applications folder, and launch. The First launch section above walks through the privacy prompts.

Is this spyware? The privacy prompts sound suspicious.

No. MockTab does not make network requests and includes no telemetry, analytics, or tracking.

If you need support, MockTab can collect tablet and driver details locally. It does not send the report anywhere. You decide whether to review, save, or share it.

MockTab needs Accessibility to deliver pen input and pressure to other apps, and Input Monitoring to read raw HID reports from the tablet. Its GPL-3.0 source code is available on GitHub.

Can MockTab run alongside Wacom’s driver or OpenTabletDriver?

Generally, no. Two tablet drivers may both try to read and control the same device, which can cause erratic input. MockTab warns you when it detects a likely conflict and suggests how to resolve it.

You can keep another driver installed if you stop its processes before launching MockTab. Utilities like App Tamer and LaunchControl can halt competing processes without uninstalling them.

How do I remove MockTab?

Quit MockTab from the menu bar, then drag MockTab.app to the Trash.

To remove its settings, delete ~/Library/Preferences/com.cyzor.mocktab.plist. You can also revoke its Accessibility and Input Monitoring permissions in Privacy & Security. MockTab does not install system extensions, daemons, or login items.

What does the name mean?

The project takes its name from the Mock Turtle in Alice’s Adventures in Wonderland, who laments no longer being what he once was.

Who developed this?

MockTab is an independent project from Jay Petronis, developed with a set of aging but reliable Wacom drawing tablets.

How can I get help?

Choose MockTab Help from the Help menu for in-app help. The Info pane has a Collect Device Data… feature that gathers system information for support. Open an issue at GitHub.
